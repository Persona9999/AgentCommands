# 具名放棄清單 —— 舊 Treasury 有錢、而**刻意不遷進新銀行**的帳戶
#
# 拍板：Tim 2026-09-17「都不搬，現狀就是終態」（TASK-0216 遷移日／TASK-0235 雙寫期）。
# 用途（兩個消費端讀**同一份**，⛔ 不各自猜）：
#   · `Cmd_Treasury op=bank_diff`：在這裡的帳戶列為「具名放棄（終態）」，**不計入閘**；
#     不在這裡而新銀行沒有的 ⇒ ⚠ **未預期缺戶**，計入閘。
#   · `UCL_BankMirror`：鏡像撞到這些帳戶時，跳過的理由標「預期」；不在清單裡的標 ⚠「非預期」。
#
# 🩸 為什麼要有這個檔：少了它，「我們決定不搬」與「鏡像漏了一戶」在對帳器上**完全同形** ——
#    而前者該安靜、後者該叫。靠註解或靠人記得都不行，那是一個每天都要重新做一次的判斷。
# ⚠ 這不是「這些錢不見了」：它們仍在舊 `Treasury/`（權威未切，D27），照樣查得到、照樣能用。
